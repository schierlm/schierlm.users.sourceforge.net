DTool 1.02

Beschreibung

DTool ist ein Java-Swing-Programm, das ER-Modelle malen und nach SQL konvertieren kann.

Installation

  1. Download der Jar-Datei dtool.jar
  2. Diese kann mit "java -jar dtool.jar" oder per Doppelklick gestartet werden. Eine Java Runtime (oder ein JDK) Version 1.2 oder höher wird benötigt.

Lizenz

Der ursprüngliche Autor, Christoph Unbehend, hat sich bereiterklärt, das Programm unter GPL zu veröffentlichen. Den Source (dtool-src.zip) inklusive Buildscripts (.bat, .sh, ant) kann man hier auch downloaden.
