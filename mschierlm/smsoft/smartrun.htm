Kann beim Start von Anwendungen automatisch das Systemdatum verstellen, Registry-Schlüssel importieren oder Dateien kopieren. Mit dem mitgelieferten Konfigurationsprogramm können die Einstellungen in SRM-Dateien gespeichert werden oder direkt in die EXE-Datei "gepatcht" werden. (SRM-Dateien müssen Sie selbst mit SmartRun verknüpfen!)
Automatically sets the system date or imports registry settings when an application is started. Includes a configuring tool which may save setting in .SRM files or  "patch" the EXE file directly (associate .SRM files with SmartRun manually!).
