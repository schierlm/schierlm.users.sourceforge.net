Dieses Kommandozeilen-Programm wird in die Verknüpfung auf ein Programm eingabaut, das nur bis zu einem bestimmten Datum läuft (z. B. Beta-Versionen, die nicht mehr weiterentwickelt werden), setzt dann vor dem Start dieser Verknüpfung das Systemdatum auf einen festgesetzten Wert und setzt eine vorgegeben Anzahl von Sekunden nach dem erfolgreichen Start das Datum wieder zurück.
sets the system date when a program is started to enable its running after its "beta time" has expired
