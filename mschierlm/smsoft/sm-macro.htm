Smart Macro ist ein einfacher Macrorekorder, der Tastatur- und optional auch Mausereignisse aufzeichnet. Diese können dann in einem Editor geändert werden. Beispielsweise können die Ausgabe von Nummern, Entscheidungen und Schleifen eingefügt werden oder auch versehentlich gedrückte Tasten gelöscht werden.
Hinweis: Der Nachfolger dieses Programms heißt IntelliMacro.NET.
Smart Macro, a macro recorder and editor which can calculate, manipulate the clipboard, communicate with the user, record keyboard and mouse actions, delays between them and window names, and much more...
Note: There is a successor of this program which is called IntelliMacro.NET.
