Here I provide my own software for downloading. I don't know if there are any bugs in it, so I set its version numbers lower than 1.0. Please send found bugs, criticism, and suggestions (e. g. icons) to me by e-mail.
This software is freeware, because at most of them (at least a lot of them) I only used knowledge provided by several PC magazines and books (CHIP, Nickles PC-Report, die besten Win'95-Geheimnisse,...)

You will get informed about my new or updated software in our "newsletter".
If you are interested in some of my source codes, request them by e-mail.
 
 

Remarks about "Platform":

 
Win95/VB: written in Microsoft Visual Basic 6.0
so they require MS-VisualBasic-runtime 6.0 (please look for a localized version matching to your Windows language)
Win95/VB+: they additionally require "SYSTRAY-Extensions" (SYSTRAY.ZIP (10 KB)) in their or the windows directory (you should prefer a localized version, this version is German)
Dos/QB: written in Microsoft QuickBasic 4.5 (no runtime library required)
