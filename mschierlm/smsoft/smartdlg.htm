SmartDialog ist ein Tool, das Fenster "beantworten" kann. Im Einzelnen wird entweder ein Button angeklickt, ein Text getippt, ein Programm gestartet, das Fenster minimiert, maximiert oder geschlossen, abgedockt, auf "Immer im Vordergrund" gesetzt oder wieder auf "Nicht immer im Vordergrund", und/oder auf eine zuvor festgesetzte Größe gesetzt. Es ist auch möglich Windows herunterzufahren oder neu zu starten und/oder ein Delay zu setzen, das nach Erscheinen des Fensters verstreichen muss.
Das Fenster kann an verschiedenen Merkmalen wie Größe, Fenstertext, Buttontext, Classnames etc. erkannt werden.
Auto-answers dialog boxes, resizes them or sets them "topmost", dependent on title, position, size and/or elements of a dialog window.
