Direct Socket Control

English

DSC (V0.6, Download, 368 KB)

Dieses Programm ermöglicht es, aktive und passive Socketverbindungen (TCP und UDP) zu beliebigen Hosts herzustellen, Daten zu diesen zu senden und zu empfangen. Zusatzmodule wie z. B. ein Forwarder oder ein "programmierbarer" Bot runden den Funktionsumfang ab.

Genaugenommen ist dieses Programm nur eine Neuimplementierung meines alten Visual-Basic-Programms "Winsock Tools".

Java Runtime Environment (Download)

Dieses Programm benötigt ein Java Runtime Environment (Java-Laufzeitumgebung) 1.4 oder höher. Dieses finden Sie für Ihr verwendetes Betriebssystem unter obigem Link.

Wenn Sie DSC mit Java 1.4 einsetzen, so schicken Sie mir bitte eine kurze Mail. Wenn ich keine Mails bekomme, wird die nächste Version von DSC Java 1.5 benötigen.
