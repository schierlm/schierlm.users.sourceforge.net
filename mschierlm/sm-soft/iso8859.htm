HTML-ISO-Webservice

Diese Website kann nützlich sein, um Texte mit Umlauten oder ähnlichen Sonderzeichen auf amerikanischen Tastaturen einzugeben.
Diese Seite funktioniert nur mit JavaScript!

Übersetzungstabelle:

Windows-Benutzer, die mit einer deutschen Tastaur all diese Zeichen (und auch noch die Windows-Zeichensatz-spezifischen Zeichen wie z. B. typografische Anfürungszeichen etc.) erzeuen möchten, sollten mal auf dieser Seite vorbeischauen.
Und hier gibt es zwei Programme zum Eingeben von (auch exotischeren) Sonderzeichen in Java (plattformunabhängig) und C# (für Windows).
