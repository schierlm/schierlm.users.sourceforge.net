AgtTool (V0.25, Download, 124 KB, Sourcecode, 80 KB)

This is the "main program". It is licensed unter GNU General Public License since Version 0.25

Features:

  • It  monitors the "Newsgroups" and the "Followup-To" fields and the search window of Forté Agent 1.8/1.9/2.0 (2.0 since version 0.25).
  • Newsgroup names can be autocompleted there by typing #.
  • You can use an alias list to use your own abbreviations for groups you X-post to regurlary.
  • In addition to that, the "tagline" (newsgroup description) of the currently selected group is shown in the title bar.
  • X-Posts can be atomatically copied into the "followup-To" field by entering "-#" before the newsgroup name.
  • Followup-To poster may be abbreviated by --#
  • X-Faces copied into the clipboard can be shown in a small window:
  • You can use F12 to show the X-Face of the current article, if there is any
  • You can use F11 to show a window where you can select some actions (e.g. jump to a parent article, copy Message-ID):
  • old subjects ("(was: ...)") are automatically stripped from the subject line. And there is help for you to create such subject lines.
  • AgtTool can automatically start Agent when it is started and can quit itself when Agent is quit.
  • you can verify X-PGP-Sig signatures
  • Randomly choose your .sig (since 0.17)
  • one hotkey for retrieving/sending everything (since 0.17)
  • superseding articles is as easy as never before (since 0.20)
  • newsgroup list, searchable by e. g. taglines (since 0.25)
